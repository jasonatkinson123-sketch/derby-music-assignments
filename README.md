# Derby Music Assignments

A colorful, browser-based music assignment system for students.

The first assignment explores Antonio Vivaldi and *The Four Seasons*. Students move through a short reading, one multiple-choice question, and two short-answer questions, then download a completed PDF for Google Classroom.

## Teacher builder

Open the site with `?builder=1` to edit the assignment content and create a shareable student link.

Student answers remain in the student's browser and are not uploaded to this repository.
